This project’s data pipeline starts by ingesting raw PFAS files in CSV, Excel, or JSON form and detecting encoding/header structure, then it fuzzy-maps raw columns to a canonical schema with optional AI-assisted column resolution through Anthropic Claude or OpenAI when the fuzzy match is ambiguous; next it resolves analytes against a local chemical reference and synonym cache, falling back to EPA CompTox for authoritative chemical identity enrichment and PubChem for unresolved or supplemental mapping, and it normalizes units to ng/L, standards non-detects, and parses dates to ISO 8601. After that it standardizes location data by validating PWSIDs against EPA SDWIS, geocoding addresses and place names through the US Census Gazetteer batch lookup, US Census Geocoder, and Nominatim when needed, deriving precision levels and coordinate confidence, then it QA-flags negatives, missing detection limits, unresolved analytes, and duplicates before splitting the canonical row set into the four relational outputs chemical, location, sample, and sample_source, writing CSV or Excel artifacts, generating a QA report workbook, and optionally loading the standardization outputs into a DuckDB database for streamlit dashboard consumption.
